Expression table format

Expression tables should mirror the DESeq2 files shipped with the atlas:

  • Tab- or comma-delimited text with a header row that includes at least Gene and log2FoldChange columns.
  • Optional padj, pvalue, and old_locus_tag columns will be used when present to style significance and resolve legacy identifiers.
  • Gene identifiers should match S. acidocaldarius locus tags (for example SACI_RS00045) or the compact CDS names used in the provided DESeq2 tables.
  • One gene per row; additional metadata columns are preserved but ignored by the arCOG loader.

Multiple tables can be queued at once. Each file name becomes the condition label shown in the charts and arCOG filters.
